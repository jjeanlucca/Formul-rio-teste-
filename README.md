📝 Formulário de Cadastro Simples

Um projeto web básico desenvolvido em HTML, CSS e JavaScript, com o objetivo de demonstrar o funcionamento de um formulário de cadastro funcional e validado no navegador.

🚀 Funcionalidades

Validação dos campos antes do envio (nome, telefone, e-mail e senha).

Exibição de alertas para campos vazios ou senha curta.

Armazenamento temporário do nome do usuário no LocalStorage.

Redirecionamento para uma tela de sucesso personalizada.

Interface limpa e responsiva com design em estilo de cartão.

🧩 Tecnologias Utilizadas

HTML5 — Estrutura da página.

CSS3 — Estilização moderna e responsiva.

JavaScript (ES6) — Lógica de validação e controle de navegação.

💡 Como Executar

Baixe ou clone este repositório.

git clone https://github.com/seu-usuario/formulario-simples.git


Abra o arquivo index.html diretamente no navegador.

Preencha o formulário e clique em Cadastrar.

Após o envio, você será redirecionado para sucesso.html, onde verá a mensagem personalizada com seu nome.
